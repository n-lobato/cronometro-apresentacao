Como usar
  1. Abra este arquivo no Google Chrome ou no Microsoft Edge.
  2. Defina a duração e clique em Abrir no canto da tela.
  3. Arraste a janelinha para o canto desejado e ajuste o tamanho pelas bordas.
  4. Inicie a apresentação em tela cheia. A janelinha continua visível por cima.
  5. Clique no cronômetro para iniciar ou pausar. Atalhos: espaço inicia/pausa, R reinicia, + e - ajustam 1 minuto.

Esta é a versão para navegador (Chrome ou Edge). Para o programa instalável no Windows, macOS ou Linux, com atalhos globais e janela sempre por cima, baixe em Releases.

Cores: verde no tempo normal, amarelo no alerta, laranja no último minuto e vermelho piscando quando o tempo estoura (passa a contar o excesso com "+").
